# Security Policy

## Supported versions

`rive-thorvg` is currently pre-1.0. Security fixes are provided on the latest mainline state only.

## Reporting a vulnerability

Please do not open public issues for suspected security vulnerabilities.

Report privately through GitHub's private vulnerability reporting with:

- Affected commit/tag
- Impact and attack scenario
- Minimal reproduction details

You will receive an acknowledgement as soon as possible, and we will coordinate disclosure and fixes before public release.

## Disclosure policy

- We prefer coordinated disclosure.
- Once a fix is available, we publish a changelog entry and remediation guidance.
